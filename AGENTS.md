# Repository instructions

## User-maintained README

The user maintains `README.md` manually. Do not open, read, review, check, rewrite, or otherwise modify it during routine work. Exclude it from broad content searches and documentation-update sweeps.

Only a direct user request to work on `README.md` authorizes reading or editing it, and that authorization applies only to the specifically requested update. Do not update it automatically when changing features, fixing bugs, or publishing the site.
