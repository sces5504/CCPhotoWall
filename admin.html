上傳名單 ↗
怎麼發布？
  1. 下載的檔案必須叫 visibility.json。若瀏覽器加上了「(1)」，請先改回原名。
  2. 按「上傳名單」，將檔案拖入 GitHub 上傳頁，按 Commit changes 提交到 main 分支。
  3. 等待部署完成（通常一至數分鐘），所有訪客會看到你選定的結果。

「新增照片」會開啟 repo 的照片資料夾。只需上傳一張大圖（JPG、PNG、WebP、GIF 或 AVIF），建置時會自動產生列表縮圖，點開則顯示上傳的大圖。已配對的大小圖會沿用原檔。提交後會自動加入照片牆最前面，請使用不同的檔名。
